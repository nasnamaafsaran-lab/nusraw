# ڕێنمایی بەکارهێنانی سیستەم بە شێوەی ئۆفڵاین

ئەم سیستەمە بە شێوەیەک دروستکراوە کە پێویستی بە ئینتەرنێت نییە و هەموو داتاکان لەسەر کۆمپیوتەرەکەت پاشەکەوت دەبن.

## ١. چۆنێتی دابەزاندن و کارپێکردن
١. ئەم فۆڵدەرە کۆپی بکە بۆ سەر ئەو کۆمپیوتەرەی دەتەوێت بیکەیت بە سێرڤەر (کۆمپیوتەری سەرەکی).
٢. بۆ کارپێکردنی سیستەمەکە، تەنها دووجار کرتە لەسەر فایلی `start.bat` بکە.
٣. پەنجەرەیەکی ڕەش دەکرێتەوە (Command Prompt)، دایمەخە! ئەمە سێرڤەرەکەیە.
٤. دوای چەند چرکەیەک، ناونیشانێک دەردەکەوێت (وەک `http://localhost:3000`).

## ٢. بەکارهێنان لەسەر کۆمپیوتەرەکانی تر
بۆ ئەوەی کۆمپیوتەرەکانی تر بتوانن سیستەمەکە بەکاربهێنن:
١. دڵنیابەرەوە هەموو کۆمپیوتەرەکان لەسەر یەک تۆڕن (هەمان WiFi یان کێبڵ).
٢. دەبێت IP Addressـی کۆمپیوتەری سەرەکی بزانیت.
   - لە کۆمپیوتەری سەرەکی، بچۆ بۆ SettingsPanelـی سیستەمەکە، لەوێ IPـیەکە نوسراوە.
   - یان لە Command Prompt بنووسە `ipconfig` و سەیری `IPv4 Address` بکە.
٣. لە کۆمپیوتەرەکانی تر، وێبگەڕ (Chrome, Edge) بکەرەوە و ئەو IPـیە بنووسە لەگەڵ `:3000` (نموونە: `http://192.168.1.10:3000`).

## ٣. پاشەکەوتکردن (Backup)
- سیستەمەکە خۆی هەموو ٢ هەفتە جارێک پاشەکەوتی ئۆتۆماتیکی دروست دەکات لەناو فۆڵدەری `backups`.
- دەتوانیت بە دەستی خۆت لە بەشی "ڕێکخستنەکان" پاشەکەوت دابەزێنیت یان بیگەڕێنیتەوە.

## ٤. تێبینی گرنگ
- نابێت فۆڵدەری `uploads`, `backups`, `database.sqlite` بسڕیتەوە، چونکە هەموو زانیارییەکان لەوێدان.
- ئەگەر ویستت سیستەمەکە بگوازیتەوە، هەموو فۆڵدەرەکە وەک خۆی کۆپی بکە.

هەر کێشەیەکت هەبوو، پەیوەندی بە بەڕێوەبەری سیستەمەوە بکە.
